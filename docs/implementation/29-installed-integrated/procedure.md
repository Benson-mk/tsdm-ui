Use an account and live queries you are authorized to exercise. Search may consume credits or quota. This procedure does not grant spending authorization; set an explicit query/debit budget for your run and avoid retries of uncertain attempts. The reference run used Edge followed by Chrome in the declared macOS development environment.

2. Record actual browser/OS versions and the manager/editor version source. Open the workspace's own Search overview. Observe current native board/time/order choices and restrictions. Edit an author or title field and verify editing alone sends no Search request. Save a private before-balance observation from a fresh native account read.

Require the native explicit zero count and the application's zero-result state, one POST/normal redirect and no automatic retry. A malformed or empty response is not zero. 8. Run the complete application E2Es for induced failure modes, expiry, missing/incompatible snapshots and direct native effectful arrivals. 9. Verify exact manifests, inspect screenshots, reconcile all ticket criteria and complete final standards/spec/BDFL review. A development run does not satisfy the separate stable-manager/browser, Windows or full-parent release matrix.
