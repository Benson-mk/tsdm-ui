## Trade-offs

- Hide the tree on the directory and remove its duplicate Chooser/All boards controls. This makes the filter the sole discovery surface there, but stops users from browsing collapsed groups without leaving the directory. Main destinations retain the drawer's extra activation on narrow screens; the Notices category select and Search's board field still serve distinct purposes.
- Use the existing in-document, account-matching catalogue and exact observed parent/subordinate links. A bare Post or a new document without usable discovery can offer fewer Boards, but never makes a speculative directory or Board read or invents links. Keep subordinate exact URLs instead of treating all links with the same Board ID as interchangeable.
- Keep navigation in one scroll container and preserve the user's Board position. At a retained deep position the destinations are offscreen until scrolling or keyboard focus brings them into view. No jump shortcut or extra layout area is provided; the account and Settings stay fixed.
- Use a border and accessible label for the collapsed current group, and `aria-current` plus a separate border for current links. These remain distinct from the focus outline in forced colors, at the cost of a small extra mark and an expanded accessible name for a collapsed current group.
- Use a uniform group-heading accent and neutral directory cards. The directory no longer encodes categories by color; category badges and dots remain in the tree and content context where source identity is established.
- Keep production pane breakpoints and sizing even at 1146 px. This preserves user-controlled collapse and resize/reset but does not give the prototype's roomier default Reader.
- Verify changed workflows through one routed Edge harness, including emulated touch, a fixture native continuation and browser-enforced keyboard traversal. This leaves Chrome, an installed manager, physical touch and assistive-technology qualification to the appropriate later checks.
