## Additional integration trade-off

Search labels and wrapped native failure text carry small optional provenance fields. For older snapshots that lack this evidence, the view preserves original label/message fragments until a fresh form or response is read; some old generated fragments therefore remain English. This favors preserving native wording over guessing that a matching string is authored by the application. It does not add a translation framework or couple the portable client to locale. This is one additional production choice beyond the six Search and five download choices already recorded; canonical linear history is a separate orchestration choice.
