## 0.1.0: the first TSDM UI release

- **Browse and read:** explore boards and rich threads, open individual posts,
  and return to your previous reading position. Search when you choose and return
  to the results without automatically running the search again.
- **Write and edit:** compose threads and replies, edit your own posts, and use
  the visual editor while preserving source text. Keep writing across workspace
  navigation, with page-session recovery and explicit handling of account changes.
- **Drafts and red packets:** manage ordinary forum drafts and prepare direct or
  draft-backed hongbao posts, with funding and submission controls.
- **Files, favorites and notices:** attach files to supported writing flows,
  download ordinary and already-accessible paid attachments, manage thread and
  board favorites, and load account notices deliberately.
- **Appearance:** choose themes, language and text size in a responsive workspace
  without losing your reading or writing context.
- **Install and update manually:** download the self-contained `tsdm-ui.user.js`
  and install it with Tampermonkey. If you installed the withdrawn v0.1.0 named
  **TSDM Workspace**, disable it before installing **TSDM UI**. The replacement
  uses the same version number with different files.

This release also includes the separately versioned forum-client library in the
Actions review package. Installation instructions and third-party acknowledgments
are linked below.
